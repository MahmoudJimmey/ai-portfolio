Three things I built and run

These are live systems. Every image is real output.

ScoopBot

AI newsroom for Address Scoop

Scans 62 news sources four times a day, writes English and Egyptian-Arabic carousels on the designer's templates and checks every figure against its source. The writer, designer and owner approve it on WhatsApp with one word. Every edit they make becomes a rule it follows next time.

A content pipeline that researches, drafts and checks, then waits for a person to approve. The same discipline partner content needs.

Built with Node.js, Gemini, WhatsApp, Playwright, Oracle Cloud

Ta2keed

Order confirmation agent

Built for the Agents at Work hackathon. It confirms cash-on-delivery orders in Egyptian Arabic, scores refusal risk, checks payment receipts with vision AI, books the courier and sends the reorder offer. Open source on GitHub. Source code
